3// toolboxes/signal/include/nk/signal/measurements/pulse_metrics.hpp
4//
5// Pulse and transition metrics for digital / step-shaped time-series.
6// The pulse-metric family: `risetime / falltime / overshoot /
7// undershoot / settlingtime / dutycycle / midcross / pulsewidth /
8// pulseperiod / pulsesep / slewrate / statelevels` family.
9//
10// Conventions:
11// * `x` is a real, sampled time-series (1-D vector).
12// * `fs` is the sample rate in Hz. `Value::Empty` (default) → fs = 1,
13// so samples are the time unit. When supplied, returned times are in
14// seconds.
15// * Reference levels come from `statelevels(x)` unless explicit levels
16// are supplied. State boundaries use the canonical defaults:
17// 10% / 90% for rise / fall, 50% for mid-state, 2% for "settled".
18// * Outputs are column vectors; empty when no transition / pulse found.
