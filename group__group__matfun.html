◆ cdf2rdf()

std::tuple< Value, Value > nk::linalg::cdf2rdf ( const Value & V,
const Value & D,
std::pmr::memory_resource * mr = nullptr )

Complex-diagonal → real-block-diagonal Schur form ([VR, DR] = cdf2rdf(V, D)).

Given complex V and complex-diagonal D from eig(A) for a real A, returns real VR, DR such that A == VR · DR · inv(VR). Conjugate eigenvalue pairs a ± b·i become real 2×2 blocks [a -b; b a] on the diagonal of DR; the corresponding pair of complex-conjugate eigenvector columns of V become real columns Re(v), Im(v) in VR.

Real eigenvalues pass through unchanged.

◆ cholupdate()

const Value & x,

std::pmr::memory_resource * mr = nullptr )

Rank-1 Cholesky update / downdate (R1 = cholupdate(R, x[, sign])).

Given an upper-triangular R from chol(A), returns R1 such that R1' * R1 == R' * R + sign * x * x' where sign is +1 (default, update) or -1 (downdate; may fail if the result is not positive-definite).

Update path uses the standard Givens-rotation rank-1 update (O(n²)). Downdate path forms R'·R − x·x' and re-cholesky's (O(n³)) — see KNOWN GAP in the source.

sign+1 for update, -1 for downdate.
mrMemory resource.
Returns

Exceptions

General p-norm condition number (c = cond(A, p)).

cond(A, p) = norm(A, p) · norm(inv(A), p) for p in {1, Inf, "fro"}. p == 2 routes through cond_2norm. Returns Inf for singular A.

p_kind: 1 → 1-norm, 2 → 2-norm, 3 → Inf-norm, 4 → Frobenius. (Integer enum to avoid a string allocation in the hot path.)

◆ condeig()

Value nk::linalg::condeig ( const Value & A,
std::pmr::memory_resource * mr = nullptr )

Eigenvalue condition numbers (c = condeig(A)).

For each eigenvalue λ_i, the condition number is s_i = 1/|y_i' x_i| where x_i is the right eigenvector and y_i the left eigenvector (both normalised). Symmetric A → all s_i == 1. Non-normal A → large s_i marks ill-conditioned eigenvalues.

Returns a column vector of length n. The 3-output form [V, D, s] = condeig(A) is exposed via the engine adapter.

◆ condest()

1-norm condition number estimate (c = condest(A)).

condest(A) ≈ norm(A, 1) * norm(inv(A), 1). The reciprocal of rcond — accurate on well-conditioned A; on near-singular A differs slightly from MATLAB's LAPACK dgecon-based estimator (Higham 1988 power-iteration approximator).
