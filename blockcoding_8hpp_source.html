5// Block linear coding — Error Correction Codes section of the
6// Communications Toolbox. Generator / parity-check matrix construction
7// (hammgen, gen2par, cyclgen) and cyclic generator polynomials
8// (cyclpoly), plus the block encoder / decoder (encode / decode).
9//
10// Everything here is GF(2) (binary) arithmetic on plain double matrices —
11// no Galois-field object type is required. BCH / Reed-Solomon (which need
12// a GF(2^m) `gf` array type) are a documented gap.
