const Value & B,
const Value & p,
std::pmr::memory_resource * mr = nullptr )

Ackermann's pole placement (K = acker(A, B, p)).

Computes the SISO state-feedback gain row K such that eig(A − B·K) = p. Implements:

\[ K = [0\ 0\ \cdots\ 0\ 1]\ \mathcal{C}(A,B)^{-1}\ \phi(A) \]

where \( \mathcal{C} \) is the controllability matrix and \( \phi(s) = \prod_i (s - p_i) \) is the desired characteristic polynomial.

Single-input only. For multi-input systems use a Riccati-based design (lqr) or split into multiple SISO loops.

Parameters
An×n state matrix.
Bn×1 input column.
pn-element vector of desired closed-loop poles.
mrMemory resource (nullptr → process default).
Returns
1×n state-feedback gain row K.
Exceptions
Errorif B has more than one column, dimensions disagree, or (A, B) is uncontrollable.
auto K = acker(A, B, Value{-2, -3, -4});
// eig(A - B*K) ≈ [-2; -3; -4]

All stability margins as a struct (S = allmargin(sys)).

Scans the open-loop frequency response for every gain crossover (|G|=1 → phase margins) and every phase crossover (∠G = −180°+360°k → gain margins), and returns a struct with the seven MATLAB fields: GainMargin, GMFrequency, PhaseMargin, PMFrequency, DelayMargin, DMFrequency (row vectors), and Stable (logical — closed-loop unity- feedback stability from the roots of den+num). The single-crossover values coincide with margin; DelayMargin = PM(rad)/ω_gc.

Continuous-to-discrete conversion (c2d(sys, Ts, method)).

Discretises a continuous-time LTI model at sample time Ts. The output struct's kind matches the input (tf → tf, zpk → zpk, ss → ss); the conversion is always done through an internal ss form, then converted back if needed.

Supported methods:

  • "zoh" (default): zero-order hold via Van Loan matrix exponential of \( \exp\!\left(\begin{smallmatrix}A & B \\ 0 & 0\end{smallmatrix}\right) T_s \).
  • "tustin": bilinear (Tustin), \( z = (1 + sT_s/2)/(1 - sT_s/2) \).

Continuous-time algebraic Riccati equation ([X, L, G] = care(A, B, Q, R)).

Solves \( A^{T}X + XA - XBR^{-1}B^{T}X + Q = 0 \) for the unique stabilizing \( X = X^{T} \succeq 0 \) via the matrix sign function of the Hamiltonian \( H = \begin{bmatrix} A & -BR^{-1}B^{T} \\ -Q & -A^{T}\end{bmatrix} \). The gain is \( G = R^{-1}B^{T}X \) and the closed-loop poles are \( \mathrm{eig}(A - BG) \).

◆ covar()

CovarResult nk::control::covar ( const Value & sys,
const Value & W,
std::pmr::memory_resource * mr = nullptr )

Steady-state covariance under white-noise excitation ([P, Q] = covar(sys, W)).

For an LTI system driven by white noise of intensity W, solves the gramian Lyapunov equation for the state covariance Q and projects it to the output covariance P:

  • continuous: A Q + Q Aᵀ + B W Bᵀ = 0 (via lyap), P = C Q Cᵀ (infinite if D ≠ 0 — white noise through a direct feedthrough).
  • discrete: A Q Aᵀ − Q + B W Bᵀ = 0 (via dlyap), P = C Q Cᵀ + D W Dᵀ.

Returns

◆ dare()

RiccatiResult nk::control::dare ( const Value & A,

const Value & Q,
const Value & R,
std::pmr::memory_resource * mr = nullptr )

Discrete-time algebraic Riccati equation ([X, L, G] = dare(A, B, Q, R)).

Solves \( A^{T}XA - X - A^{T}XB(R + B^{T}XB)^{-1}B^{T}XA + Q = 0 \) for the stabilizing \( X \). Builds the symplectic matrix and applies a Cayley transform (unit disk → left half-plane) so the same sign-function machinery as care selects the stable subspace. The gain is \( G = (R + B^{T}XB)^{-1}B^{T}XA \), closed-loop poles \( \mathrm{eig}(A - BG) \) (inside the unit circle).

Convert tf coefficients to controllable canonical state-space.

Produces the controllable canonical realisation (companion-matrix form):

\[ A = \begin{pmatrix} 0 & 1 & 0 & \cdots & 0 \\ \vdots & & & & \\ 0 & 0 & \cdots & 0 & 1 \\ -a_n & -a_{n-1} & \cdots & & -a_1 \end{pmatrix},\quad B = \begin{pmatrix}0 \\ \vdots \\ 0 \\ 1\end{pmatrix} \]

with C[k] = b[n − k] − b[0]·a[n − k] and D = b[0]. The numerator must be no longer than the denominator (proper rational).
