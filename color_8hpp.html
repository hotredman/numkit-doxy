Detailed Description

Colour-space conversions, Lab helpers, colormaps.

Image shape convention. Most colour-space conversions accept either an H × W × 3 image or an N × 3 colormap (rows = pixels, cols = channels).

Output class. rgb2* / *2rgb / rgb2lab / lab2rgb / rgb2xyz / xyz2rgb return DOUBLE.

Integer input. When the input is integer-typed, values are rescaled by the class range first; double / single inputs in [0, 1] are taken at face value.
