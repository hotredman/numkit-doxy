3// nk::function_ref<Sig> — lightweight, non-owning callable view.
4//
5// Two-pointer type-erased reference to any callable matching the
6// signature `Sig`. Cheap to copy (16 bytes on 64-bit), no allocation,
7// no virtual dispatch overhead (single indirect call through a thunk).
8// The lifetime of the underlying callable is the caller's
9// responsibility — function_ref does NOT own it.
10//
11// Used for "matlab-style function handle" callbacks in the numerical
12// library API (fzero, integral, fminsearch, cellfun, …). The engine
13// adapter builds a stack-resident lambda that wraps a function-handle
14// Value, then passes a function_ref view to the library function.
15// The library function calls the callback as many times as needed and
16// returns; the lambda + function_ref both live in the adapter frame.
17//
18// Inspired by C++26's std::function_ref and tcb::function_ref.
19
