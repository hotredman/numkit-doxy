Detailed Description

Column-wise normalisation (Y = normalize(A, method)).

Supported method:

  • "zscore" (default): (A - mean) / std (population std, normFlag=0)
  • "center": A - mean
  • "scale": A / std
  • "range": (A - min) / (max - min)
  • "norm": A / sqrt(sum(A²)) (unit ℓ² norm per column)
  • "medianiqr": (A - median) / iqr (robust)
Parameters
AInput matrix.
methodNormalisation method name (see list above).
paramOptional method parameter (Value::Empty → default): for "range" a [lo hi] vector; for "norm" the exponent p (Inf allowed); for "scale" a divisor string ('std'/'first'/'iqr'/'mad') or numeric; for "center" 'mean'/'median' or numeric.
mrMemory resource (nullptr → process default).
Returns
{n, c, s} — n the normalised matrix (same shape as A), c the centering value C, s the scaling value S (MATLAB [N,C,S]=normalize): one value per operating slice, 1×1 for a vector / 1×W for a matrix, with n == (A - c) ./ s.
