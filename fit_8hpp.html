Detailed Description

Distribution fitters (*fit) and negative-log-likelihood scoring (*like).

Each fitter returns scalar (or per-element) parameter estimates plus 1 × 2 confidence intervals at level 1 - alpha. Default alpha = 0.05 (95% CI).
