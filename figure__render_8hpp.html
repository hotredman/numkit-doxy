Detailed Description

Engine-side figure renderer — the software path behind saveas/exportgraphics/print (portion 32).

Produces a pixel-space DISPLAY LIST from a FigureState, plus two backends: • renderFigureSvg — vector SVG (text as <text>) • renderFigureRgb — rasterised RGB buffer (built-in 5×7 bitmap font, Bresenham lines, scanline polygon fill)

Deliberately STL-only and Value-free (same contract as the rest of the figure layer); the bundle's export_reg.cpp turns the RGB buffer into PNG bytes via the image toolbox and writes through the fs.

Scope (portion 32): vector chart types — line, stairs, stem, scatter, bar, barh, area, errorbar — on linear/log axes with grid, limits, tick formats, dir reverse, subplot tiling, legend, sgtitle. NOT yet rendered: 3-D surfaces/contours, imagesc/heatmap (colormap port), polar, text overlays, yyaxis right-scale, annotations — tracked in bugs/opened/graphics/handle-surface-gaps.md sibling export-gaps file.
