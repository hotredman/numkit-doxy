3// toolboxes/control/include/nk/control/riccati/riccati.hpp
4//
5// Algebraic Riccati equation solvers.
6//
7// care: continuous-time ARE AᵀX + XA − XBR⁻¹BᵀX + Q = 0
8// dare: discrete-time ARE AᵀXA − X − AᵀXB(R + BᵀXB)⁻¹BᵀXA + Q = 0
9//
10// Both are solved by the matrix sign-function method (no Schur
11// ordering): a Newton iteration drives an embedding matrix to its
12// sign, whose stable invariant subspace yields X via a small
13// least-squares solve. care embeds the Hamiltonian directly; dare
14// embeds the symplectic matrix through a Cayley transform that maps the
15// unit disk onto the left half-plane so the same sign machinery applies.
16//
17// Practical for the state dims that show up in textbook control
18// problems (n ≲ 32). dare requires a nonsingular A (the explicit
19// symplectic form needs A⁻¹); the singular-A pencil path would need a
20// QZ solver we do not have yet.
