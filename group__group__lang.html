◆ assertCond()

void nk::runtime::assertCond ( Span< const Value > args)

Throw on a false condition (assert(...)).

Forms:

  • assert(cond) → generic message on failure
  • assert(cond, msg, arg1, ...) → sprintf-formatted message
  • assert(cond, id, msg, arg1, ...) → identifier + formatted message (id must contain :)
  • assert(cond, MException-struct) → use struct fields

Returns normally if cond is non-zero.

Parameters
argsArguments per the forms above.
Exceptions
ErrorCondition is false (form-dependent identifier / message).

void nk::runtime::error ( Span< const Value > args)

Throw an Error (error(...)).

Accepts any of:

  • error() → generic "Error"
  • error(msg) → msg literal
  • error(msg, arg1, ...) → sprintf-formatted message
  • error(id, msg, ...) → identifier + formatted message (id must contain :)
  • error(MException-struct) → rethrow identifier / message fields from the struct
Parameters
argsArguments per the forms above.
Exceptions
ErrorAlways (never returns).
