◆ load()

void nk::runtime::load ( Engine & engine,
Environment & env,
Span< const Value > args,
size_t nargout,
Span< Value > outs )

Load workspace variables from an ASCII file (load filename / S = load(filename)).

Reads the file through engine's VFS, parses ASCII matrices, and either:

  • (no-LHS form) writes each parsed variable into env using a stem-derived var name, or
  • (LHS form) returns a struct with one field per variable.
Parameters
engineEngine context (VFS).
envVariable environment to assign into.
args(filename [, var1, var2, …]).
nargoutNumber of requested outputs (0 = assign into env, 1 = return struct).
outsOutput slot for the struct form.
Exceptions
ErrorOn VFS failure, parse failure, or unknown variable.
See also
save

◆ save()

void nk::runtime::save ( Engine & engine,
Environment & env,
Span< const Value > args )

Save workspace variables to an ASCII file (save filename var1 var2 ...).

Looks each requested variable up in env, formats it as ASCII, and writes the file through engine's VFS. With no variables specified, saves the entire workspace.

Parameters
engineEngine context (VFS).
envVariable environment to read from.
args(filename [, var1, var2, …]) — strings or symbol names.
Exceptions
ErrorOn VFS failure or unknown variable name.
See also
load
