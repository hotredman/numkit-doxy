Detailed Description

Dependency DAG over statement indices.

Edge i → j means "j must re-run when i re-runs" (j reads the nearest def i provides, or j is a wildcard reading everything, or i is a wildcard and j follows it).

◆ dirtySetFor()

std::vector< size_t > nk::DependencyGraph::dirtySetFor ( const std::string & var) const

Indices that must re-run when var is assigned externally.

A PURE DEFINITION of var (var = literal — writes, never reads) is SKIPPED: setParam replaces it (re-running would reset the slider). Affected = readers + merge-writers + wildcard statements that may invisibly write var + transitive closure.

Element-level variant: external write of ONE CELL (the table editor's setParamElement).

Affected = statements whose READ regions touch (r,c) on var + wildcards + statements that merge-write var while also reading it + transitive closure. Statements that only WRITE regions of var (definitions of other cells) stay clean — their inputs did not change.
