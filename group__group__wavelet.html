Extract approximation coefficients at a given level (appcoef).

The appcoef(C, L, wname, level) operation.

  • level == nMax = length(L) - 2 (the default if level == -1) returns the coarsest cA stored verbatim at the front of C.
  • level < nMax rebuilds the approximation by running idwt nMax - level times.

◆ ddencmp()

DdencmpResult nk::wavelet::ddencmp ( const std::string & opt,
const std::string & type,
const Value & x,
std::pmr::memory_resource * mr = nullptr )

Default threshold / settings for wavelet denoising or compression.

Estimates the noise level from the finest-detail coefficients of a 1-level db1 DWT — σ̂ = median(|cD₁|)/0.6745 — and returns the default parameters for opt = "den" (denoising) or opt = "cmp" (compression):

  • den: thr = sqrt(2·log(n))·σ̂ (universal threshold), sorh = 's'.
  • cmp: thr = median(|cD₁|), sorh = 'h'.

keepapp = 1 in both cases. Only type = "wv" (wavelet) is supported; "wp" (wavelet packet) is not yet implemented.

Parameters
opt"den" (denoise) or "cmp" (compress).
type"wv" (wavelet); "wp" is rejected.
xInput signal.
mrMemory resource (nullptr → process default).
Returns
{thr, sorh, keepapp} (see DdencmpResult).
Exceptions
Erroron an unknown opt/type or "wp".
See also
wentropy, wthresh, wdenoise

◆ dwt()

std::pair< Value, Value > nk::wavelet::dwt ( const Value & x,
const std::string & wname,
std::pmr::memory_resource * mr = nullptr )

Single-level discrete wavelet transform ([cA, cD] = dwt(x, wname)).

Decomposes the 1-D signal x into an approximation band cA (lowpass) and a detail band cD (highpass), each downsampled by 2. The extension mode is fixed at 'sym' (whole-point symmetric reflection).

Output length per band: \( \lfloor (N + L_f - 1)/2 \rfloor \) where \( L_f \) is the filter length.

Parameters

wnameWavelet name — "haar", "db1".."db10", "sym2".."sym10", "coif1".."coif5".
mrMemory resource (nullptr → process default).
Returns
(cA, cD); bind via auto [cA, cD] = dwt(x, wname);.
Exceptions
Erroron unknown wavelet name.
auto [cA, cD] = dwt(signal, "db4");

Reconstructs the approximation (type = "a") or a single detail band (type = "d") of (c, l) at level n, with all other bands zeroed out before running waverec. Output is a row of length |x| (= l(end)).

  • type = "d": n ∈ [1, N]. Reconstructs only the detail at level n.

Pass n = -1 to use the default (n = N = length(l) - 2).

Element-wise wavelet coefficient thresholding (Y = wthresh(X, sorh, T)).

Applies one of two thresholding rules at level T:

  • sorh = "h" (hard): \( Y = X\,\cdot\,\mathbb{1}(|X| > T) \) — zero out coefficients below the threshold, leave the rest unchanged.
  • sorh = "s" (soft): \( Y = \text{sign}(X)\,\max(|X|-T,\,0) \) — shrink every coefficient toward zero by T.

Shape of X is preserved; output type is always DOUBLE.

Parameters
XInput coefficients (any numeric Value).
sorh"h" or "s".
TNon-negative threshold.
mrMemory resource (nullptr → process default).
Returns
Thresholded coefficients.
Exceptions
Errorif sorh is not "h"/"H"/"s"/"S".
