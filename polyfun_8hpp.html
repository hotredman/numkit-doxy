using nk::FnHandle

MATLAB-style function-handle callback.

args carries the per-call inputs; outs is the caller-allocated output buffer (its .size() is the requested nargout). mr is the caller's memory resource — the callback should honour it when constructing the output Values so PMR allocation chains through. The callback fills outs[0..outs.size()).
