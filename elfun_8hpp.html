Detailed Description

Elementary mathematical functions (trigonometry, exp, log, complex numbers, rounding).

Provides an engine-free, highly optimized C++ interface for MATLAB-compatible elementary mathematical functions, featuring Highway SIMD vector acceleration and thread parallelism.
