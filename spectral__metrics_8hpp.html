Detailed Description

Spectral measurement functions.

Conventions:

  • fs defaults to Value::Empty. With fs.isEmpty() frequencies span [0, π] rad/sample; with fs > 0 they span [0, fs/2] Hz.
  • Functions compute the PSD internally via a single-segment periodogram.
