Detailed Description

Image type-conversion helpers.

Scaling conventions:

  • Float input is assumed to be in [0, 1] (clipped on conversion to integer).
  • Integer ↔ float conversions scale by class range:
    • uint8 ↔ [0, 1]: ÷255 / ×255
    • uint16 ↔ [0, 1]: ÷65535 / ×65535
    • int16 ↔ [0, 1]: (x + 32768) / 65535 / round(x · 65535) - 32768
  • Integer-to-integer conversions use bit-replication for upscaling (uint8 → uint16: 0xAB → 0xABAB) and rounded scaling for downscaling.
